## 2. 設計理念

開啟網頁即可看見自由游動的魚群。操作不以闖關或競爭為目的，使用者可點擊水面、移動游標、餵食及切換燈光，在放鬆的環境下即時觀察魚群的反應。

## 3. 功能需求

### F1 魚群自動游動
- 預設至少 5 隻魚（初始為 5 隻）。
- 魚隻持續游動，大小、顏色、速度與路線各有差異。
- 接近邊界時平順轉向，魚隻完整留在水族箱內。
- 魚的頭尾朝向應隨左右移動方向改變；轉向時只做**水平鏡像翻轉**，身體維持正立、不會上下顛倒。
- 可保留小幅度上下游動傾斜（建議不超過約 13°），但不得旋轉至倒立。

### F2 點擊產生氣泡
- 在水族箱點擊或觸碰時，在接觸位置產生多顆大小不一的氣泡。
- 氣泡緩緩上升、淡出，生命週期結束後移除。

### F3 魚群追逐滑鼠／觸控
- 游標進入水族箱或使用者觸碰時，魚群以不同靈敏度緩慢靠近。
- 保留魚與互動點之間的距離，避免所有魚完全重疊。
- 游標離開水族箱後回歸自由游動；手機可透過觸控短暫吸引魚群。

### F4 海底環境
- 藍綠色分層漸層、柔和光束、漂浮微粒及氣泡。
- 底部有海草、珊瑚、岩石等以 Canvas 繪製的裝飾。
- 不使用外部圖片或 API。

### F5 控制面板
- **餵食**：在水中投放顆粒，魚群優先靠近並吃掉飼料。
- **增加魚**：增加一隻魚，外觀與速度隨機分配，更新數量；最多 40 隻。
- **移除魚**：每次按下移除一隻魚，魚群數量立即更新；最少為 0 隻。若沒有魚可移除，顯示提示且不可變成負數。
- **切換燈光**：切換一般／夜間發光模式。
- **重新開始**：重設為初始 5 隻魚、一般燈光、無飼料或短暫氣泡。

### F6 餵食回饋
- 投放飼料後，魚群優先追逐最近的可用飼料；接近時視為吃掉。
- 飼料若無魚吃到，會在一定時間後自行移除。
- 餵食結束後給予簡短文字提示。

## 4. 互動行為優先順序

1. 有飼料時優先朝飼料游動。
2. 無飼料且游標在水族箱內／剛觸控時，朝互動點靠近。
3. 其餘時間自由游動。
4. 無論哪種狀態，魚都必須受到邊界約束。

## 5. UI 配置

1. **頂部**：`Dream Aquarium`、`YOUR LITTLE UNDERWATER WORLD`、簡短介紹。
2. **資訊列**：`我的水族箱`、魚群數量、目前光照模式。
3. **主視覺**：以 Canvas 為互動區，佔據頁面大部分空間。
4. **底部控制面板**：餵食、增加魚、移除魚、切換燈光、重新開始。
5. **提示文字**：初次進入時顯示滑鼠／觸控及點擊的操作方式；完成餵食後顯示回饋。

## 7. 技術與限制

- 所有 HTML、CSS 與 JavaScript 都寫入 `index.html`，不需打包或安裝依賴。
- Canvas 繪製水族箱內容，HTML/CSS 繪製文字及控制面板。
- 動畫使用 `requestAnimationFrame`，位移依影格時間差計算。
- Canvas 依容器寬高與裝置像素比例調整，並控制像素比以平衡效能。
- 互動支援 Pointer Events，包含桌面滑鼠與行動裝置觸控。
- 互動物件需在生命週期結束後移除，避免持續累積。
- 無資料庫、帳號、API 金鑰、外部資源或必要的 `localStorage`。

## 8. 操作流程

開啟網頁 → 觀看初始 5 隻魚自由游動 → 移動滑鼠／觸碰吸引魚群 → 點擊產生氣泡 → 使用餵食、增加魚、移除魚或切換燈光 → 隨時重新開始。

## 9. 驗收標準

- [ ] 首次開啟可看見 5 隻魚自動游動。
- [ ] 魚隻不會游出水族箱，且轉向時頭尾朝向正確、魚身不會上下顛倒。
- [ ] 點擊／觸碰可產生多顆上浮並消失的氣泡。
- [ ] 游標移動或觸控能吸引魚群，且不同魚有不同反應。
- [ ] 餵食會產生飼料，魚群聚集、吞食，餵食結束有提示。
- [ ] 增加魚會增加一隻，數字同步更新；上限 40 隻。
- [ ] 移除魚每次減少一隻且數字同步更新；魚群為 0 時顯示提示、不會成為負數。
- [ ] 燈光按鈕可切換一般與夜間模式。
- [ ] 重新開始恢復預設魚群、燈光與環境。
- [ ] 桌面與手機畫面及按鈕可正常使用。
- [ ] 本機直接開啟 `index.html` 即可使用，亦可部署 GitHub Pages。

## 11. 部署

將 `index.html` 放置在 GitHub Repository 根目錄，至 **Settings → Pages** 選擇從部署分支（例如 `main`、`/(root)`）發布；`SPEC.md` 僅供文件使用，不影響部署。

> 核心原則：先確保魚能動、互動有效，再逐步提升視覺細節。
